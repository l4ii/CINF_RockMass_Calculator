# RMR 工程总览：台账优先设计

## 目标

工程总览用于逐点核对 RMR 评分，并在同一页面判断工程段整体质量。页面的首要阅读对象是点位 A1-A6 分值表，而不是统计图表。

## 页面顺序

1. 保留工程名称、返回点位列表和导出报告。
2. 将筛选与排序收紧为单一工具条，保留矿岩类型、RMR 范围、参数范围、排序和清除筛选。
3. 紧接工具条显示点位分值表，A1-A6、RMR 和等级默认可见。
4. 每个点位的实际输入、评分说明和工程参数保持行级折叠，通过末列箭头展开。
5. 点位表下方显示四张分析图：等级分布、RMR 区间分布、参数与 RMR、参数平均分贡献。
6. 图表下方显示当前点位、可计算点位、平均 RMR、中位数和范围的统计行。

不再在页面顶部显示点位总数、平均 RMR 和等级分布的独立大卡片，避免与页面底部的数据分析重复。

## 视觉与交互

- 不使用“图表”“数据分析”“点位分值”等总标题将页面切割为多个平级章节。
- 点位表是视觉主区域，使用完整宽度并保留横向滚动；表头固定在表格顶部。
- 图表在点位表之后以两列网格显示。等级分布和 RMR 区间分布位于第一行，另外两张图位于第二行。
- 图表不再触发或修改表格筛选。等级条、区间柱和平均分条支持悬停读数；散点图继续使用点位名称、实际参数和 RMR 的提示信息。
- “清除筛选”是唯一的清除动作，同时恢复筛选条件和默认排序。
- 筛选结果、表格和图表使用同一份过滤后的点位数据。

## 数据与组件边界

- `RmrCaseSummaryPage` 负责项目标题、筛选状态、排序状态、点位表、行级展开和区域顺序。
- `RmrOverviewControls` 只负责筛选、排序和清除动作，不控制参数列或图表可见性。
- `RmrOverviewCharts` 只负责图表和统计行展示，不写入筛选状态。
- 现有 `applyRmrOverviewFilters`、`sortRmrOverviewRows` 和 `getRmrOverviewStats` 继续作为表格与图表的统一数据来源。

## 状态与边界情况

- 没有点位时，主表显示空状态，图表显示无可计算数据，统计行显示 0 或破折号。
- 待复核点位保留在表格中；分析是否包含它们仍由现有复选项决定。
- 清除筛选会关闭所有已展开的点位详情并恢复默认排序，确保结果可预测。
- 展开详情不改变表格筛选、排序或图表数据。

## 验证

- 点位表在筛选工具条之后、图表之前渲染。
- A1-A6 表头和每行分值默认显示，实际输入在展开前不显示。
- 顶部大统计卡和三个重复总标题不再出现。
- 四张图表与下方统计行默认可见，且图表不提供筛选或清除图表筛选控件。
- 运行 RMR 组件测试、类型检查和生产构建。
